Coldcard's five-year flaw reveals a hardware wallet testing gap

What:Kraken's security chief explained the bug survived five years because auditors verified the intended random number generator existed in the codebase, but never verified it was invoked during key generation.
Source:Cointelegraph
So what: This is a concrete, cheap test to add to our own pipeline: statistical entropy assertions on generated keys in CI, plus a runtime check that the hardware RNG path was actually exercised. Worth a security-hardening ticket this sprint, and it makes a strong trust-page claim once shipped.
